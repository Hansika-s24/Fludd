# Fludd: guide for coding agents

Every coding agent working in this repo (Codex, ChatGPT, Claude Code or any other) follows the same rules.

1. Read `CLAUDE.md` in this folder first. It is the project guide: who owns which folders, the working rules, and the hackathon rules that bind this repo.
2. Then read `prep/PLAN.md` and the guide for the person you are working with (`prep/HACKER-HARSHITH.md` or `prep/HACKER-HANSIKA.md`).
3. Edit only the folders that person owns. Never change `docs/contracts.md` without asking both people.
4. Commit messages: conventional, imperative, no AI attribution.
5. Any AI tool used on this project must be named in the README's "How AI was used" section. If you are a tool not yet listed there, tell the person so they can add you.

The web app has its own agent notes in `web/AGENTS.md` (this Next.js version has breaking changes; read its bundled docs before writing code).
